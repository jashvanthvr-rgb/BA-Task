# BA-Task 12
Tableau Public Data Analysis Dashboard
Project Overview

This project focuses on exploring a dataset using Tableau Public to identify meaningful patterns, trends, and relationships. An interactive dashboard is created using four different visualizations to help users understand the data and gain useful business insights.

Objectives
Analyze the dataset and identify important patterns and trends.
Create an interactive dashboard using Tableau Public.
Use visualizations to compare categories and understand data distribution.
Provide key findings, suggestions, and recommendations based on the analysis.
Visualizations Used
1. Pie Chart

The pie chart displays the proportion of each category in the dataset. It helps identify the categories with the largest and smallest shares.

2. Histogram

The histogram shows the frequency distribution of numerical values. It helps identify common value ranges, patterns, and unusual observations.

3. Treemap

The treemap represents categories using rectangles of different sizes. It helps compare the relative contribution of categories and identify the most and least significant groups.

4. Circle Chart

The circle chart compares different categories using circles of varying sizes and colors. It helps users quickly identify differences between categories and recognize important patterns.

Interactive Features
Interactive Filters: At least two filters allow users to explore specific categories, dates, regions, or other available dimensions in the dataset.
Dashboard Interactivity: Selecting elements in supported charts allows users to explore related information across the dashboard.
Key Findings
The pie chart helps identify the categories that account for the largest and smallest proportions of the dataset.
The histogram reveals the distribution of numerical values and highlights the most frequent ranges.
The treemap and circle chart help compare category contributions and identify areas of stronger or weaker performance.

Note: These findings should be updated with actual observations from the dataset.

Suggestions and Recommendations
Investigate categories with low contributions to understand the reasons for their performance and identify opportunities for improvement.
Use the dashboard filters to examine category-level patterns and support more informed business decisions.
Conclusion

This project demonstrates how Tableau Public can be used to analyze data through interactive visualizations. The four charts provide complementary views of category proportions, numerical distributions, and relative contributions. The interactive dashboard makes it easier to explore the dataset and supports data-driven decision-making.

Tools Used
Tableau Public
Dataset provided for analysis
Project Deliverable

An interactive Tableau Public dashboard containing four visualizations, at least two interactive filters, key findings, recommendations, and an overall conclusion.
